# KAI Public Safe Code Sampling Pack

This pack contains selected KAI code samples prepared for public disclosure.

Scope:
1. KAI only branding.
2. No internal vendor references.
3. No platform keys, wallet addresses, payment links, private endpoints, or operational secrets.
4. No client, partner, or ecosystem product names outside KAI.
5. Samples are simplified for demonstration and technical review.

Included files:
1. `KAI_public_trace_logger.py` — append only audit event logger.
2. `KAI_public_decision_trace_schema.json` — public safe 18 field decision trace schema.
3. `KAI_public_eval_harness.py` — lightweight evaluator for response safety and role discipline.
4. `KAI_public_sync_controller.py` — minimal file index and integrity controller.
5. `KAI_public_agent_bus.js` — minimal intent routing and role dispatch sample.
6. `KAI_public_interface.html` — standalone public interface demo.

Disclosure note:
These files are public safe technical samples. They are not the complete KAI system, training corpus, production runtime, or private governance layer.
